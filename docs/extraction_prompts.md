# VE5 截图数据提取 Prompt 文档

## 目的
引导大模型正确从金融App截图的OCR文本中提取持仓信息，避免金额与产品名称混淆。

## 常见截图格式示例

### 1. 东方财富证券（股票/ETF持仓）
典型格式：
```
酒ETF 512690 14000 0.498 -1416.74 5558.00
纳指100ETF 513100 3000 6.425 15726.00 19276.00
可用资金 45287.55
总资产 171848.55
```
提取规则：
- 每行第一个词是产品名（如"酒ETF"、"纳指100ETF"）
- 金额通常在最右侧（市值），可能有多个数字（代码、数量、单价、盈亏、市值）
- **取最后一个大于1000的金额作为持仓市值**
- 不要提取6位数字（如512690是基金代码，不是金额）

### 2. 招商银行（理财/基金持仓）
典型格式：
```
朝朝宝
今日收益 0.42元 持仓金额 17182.14元
广发纳斯达克生物科技 9575.91
持仓收益 +123.45 持仓金额 9575.91
```
提取规则：
- 产品名和金额可能不在同一行
- **"持仓金额"后面的数字才是持仓金额**，"今日收益"、"持仓收益"后面的数字是收益，不是持仓金额
- 如果看到"持仓金额 XXXX.XX"，提取该金额
- 如果产品名单独行，下一行有"持仓金额"，关联提取

### 3. 摩根基金/天弘基金（基金持仓）
典型格式：
```
摩根全球多元配置人民币C
121364.13
摩根日本精选A
2811.58
```
提取规则：
- 产品名单独行，金额在下一行
- 金额通常是一个独立的数字行

## 关键提取规则

1. **金额区分**：
   - 持仓金额 = 用户实际投入/当前市值（通常较大，>1000）
   - 收益金额 = 今日收益/持仓收益（通常较小，<100）
   - **绝对不要把收益金额当作持仓金额**

2. **产品名识别**：
   - 产品名通常是中文+英文字母组合
   - "ETF"、"QDII"、"A/B/C"是产品名的一部分，不要省略
   - "酒ETF"不要简化为"ETF"

3. **排除项**：
   - 总资产、证券市值、可用资金、可取资金（这些是汇总，不是持仓）
   - 收益率、涨跌幅（百分比数据）
   - 功能标签（"直接可用"、"快速赎回"、"最高7日年化"）

## Prompt 使用位置
Prompt内容嵌入在 `receiver/llm_extractor.py` 的 `_PROMPT_HOLDINGS` 变量中，由 `ve4_llm_extract_holdings()` 函数调用。

当LLM不可用时，自动回退到 `receiver/pipeline.py` 的 `_regex_extract()` 正则兜底提取。
