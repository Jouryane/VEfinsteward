# VE4 蓝牙文件接收 — 用户指引

> **本文档指导用户如何设置蓝牙配对、通过蓝牙上传文件到本地主机，以及了解文件到达后的自动处理流程。**

---

## 一、准备工作

### 1.1 确认硬件条件

| 条件 | 要求 |
|------|------|
| 电脑 | Windows 10/11，内置蓝牙或外接蓝牙适配器 |
| 手机 | Android 或 iOS，支持蓝牙文件传输（OBEX） |
| 距离 | 手机和电脑距离在 10 米以内 |

### 1.2 确认软件条件

- [ ] 本地主机已启动 VE4 服务（`uvicorn api.main:app`）
- [ ] 已安装并启动 `watcher.py` 监控程序
- [ ] 手机已安装支持蓝牙文件传输的文件管理器（推荐：Android 用系统自带"文件"App，iOS 用"文件"App）

---

## 二、蓝牙配对设置

### 2.1 电脑端设置

**步骤 1：打开蓝牙**
1. 点击 Windows 任务栏右下角的"操作中心"（通知区域）
2. 点击"蓝牙"图标，确保蓝牙已开启
3. 右键点击蓝牙图标 → "转到设置"

**步骤 2：设置为可被发现**
1. 在"蓝牙和其他设备"设置中，确保"蓝牙"开关已打开
2. 点击"更多蓝牙选项"
3. 在"选项"标签页中，勾选"允许蓝牙设备查找这台电脑"
4. 勾选"在通知区域显示蓝牙图标"
5. 点击"应用" → "确定"

### 2.2 手机端设置

**Android：**
1. 打开"设置" → "蓝牙"
2. 开启蓝牙
3. 点击"配对设备"或"扫描"

**iOS：**
1. 打开"设置" → "蓝牙"
2. 开启蓝牙
3. 等待搜索可用设备

### 2.3 执行配对

1. 在手机的蓝牙设备列表中，找到你的电脑名称（如"DESKTOP-XXXX"）
2. 点击电脑名称开始配对
3. **电脑端会弹出配对请求**，显示一个 6 位数字验证码
4. **手机端也会显示相同的验证码**，确认后点击"配对"
5. 电脑端点击"是"或"允许"完成配对

> **提示**：配对成功后，手机和电脑会记住彼此，下次无需重新配对。

## 三、文件上传方法

### 3.1 Android 手机上传文件

**方法一：通过系统文件管理器**
1. 打开手机的"文件"App（或任意文件管理器）
2. 找到你要上传的文件（截图、Excel、CSV 等）
3. 长按文件 → 点击"分享"或"发送"
4. 在分享菜单中选择"蓝牙"
5. 在设备列表中选择已配对的电脑名称
6. 等待传输完成

**方法二：通过相册分享截图**
1. 打开"相册"或"照片"App
2. 找到要上传的截图（如银行账单截图、证券持仓截图）
3. 点击"分享"按钮
4. 选择"蓝牙"
5. 选择已配对的电脑名称
6. 等待传输完成

**方法三：通过银行/券商 App 导出后直接分享**
1. 在银行 App 中导出账单（Excel/CSV）
2. 导出完成后，点击"分享"
3. 选择"蓝牙" → 选择电脑名称
4. 文件将直接传输到 ve4 接收目录

### 3.2 iOS 手机上传文件

**限制说明**：
iOS 对蓝牙文件传输有严格限制，**无法直接通过蓝牙发送任意文件到电脑**。但有以下替代方案：

**方案 A：AirDrop 替代（局域网传输）**
1. 确保手机和电脑在同一 WiFi 网络
2. 在 iPhone 上打开"文件"App
3. 选择文件 → 点击"分享"
4. 选择"AirDrop"
5. 如果电脑是 Mac，直接选择 Mac 名称
6. 如果电脑是 Windows，使用第三方 AirDrop 兼容工具（如"Dell Mobile Connect"）

**方案 B：通过 VE4 移动端 App 上传**
1. 打开 VE4 移动端 App
2. 进入"数据收集" → "选择文件"
3. 选择要上传的文件
4. App 会自动通过局域网发送到本地主机（不经过蓝牙）

> **建议**：iOS 用户优先使用 VE4 移动端 App 的文件上传功能，绕过蓝牙限制。

## 四、文件到达后的自动处理

### 4.1 智能文件路由

VE4 会自动判断文件类型，选择合适的处理通道。

**快速通道（直接处理，不调模型）：**
- CSV/Excel 列名匹配已知银行格式
- 文件名含"银行"、"持仓"、"账单"、"Screenshot"等关键词

**模型辅助通道（调本地轻量模型判断）：**
- 文件名无关键词的截图 → 模型判断"这是什么截图？"后定向处理
- 未知列名的 CSV → 模型识别数据类型后处理
- 未知格式的 Excel → 模型判断数据类别

**质量复核（模型复查，纠正明显错误）：**
- OCR 文本是否包含乱码或无效内容
- 分类是否合理（含"美团"是否分了"外卖"类？）
- 金额/日期是否有明显异常

所有模型调用**不超过 2 秒**，模型仅做"是/否/选一个"级别判断，不做长文本生成。

### 4.2 完整处理流程

当你通过蓝牙发送文件后，以下流程**全自动执行**，无需任何手动操作：

```
[手机发送文件] --蓝牙--> [电脑蓝牙接收]
    |
    v
[文件落入 ve4/incoming 目录]
    |
    v
[Watcher 检测到新文件]
    |
    v
[等待文件传输完成（3秒稳定检测）]
    |
    v
[智能路由判断]
    ├── 文件名含"招商银行流水" → 快速通道 → 直接解析
    ├── 文件名为 "IMG_0012.png" → 模型判断 → 识别为银行截图 → OCR
    └── 文件名为 "data.csv" → 模型判断列名 → 识别为消费账单 → 结构化解析
    |
    v
[内容提取]
    ├── 截图 → OCR（中文+英文）
    ├── CSV/Excel → pandas 结构化解析
    └── PDF → pdfplumber 文本提取
    |
    v
[模型质量复核（可选）]
    ├── OCR 乱码检测
    ├── 分类合理性修正
    └── 数据异常警告
    |
    v
[数据还原（清洗 + 标准化 + 映射为 ve4 统一格式）]
    |
    v
[双路存储]
    ├── 存入 SQLite（结构化数据，加密存储）
    └── 存入 ChromaDB（向量数据，RAG 语义检索）
    |
    v
[更新财务画像]
    |
    v
[文件移动到 processed/ 目录]
    |
    v
[你可以在 PWA 面板查看新数据]
```

### 4.2 查看处理结果

1. 打开浏览器，访问 PWA 面板（地址：`http://<本地主机虚拟IP>:8000`）
2. 进入"财务中枢"页面
3. 新导入的数据已自动反映在账户总览和资产配置中
4. 点击"数据同步"页面可查看最近处理的文件列表

### 4.3 处理失败怎么办？

如果文件处理失败，文件会被移动到 `ve4/incoming/failed/` 目录，失败原因分类如下：

| 失败类型 | 原因 | 解决方法 |
|---------|------|---------|
| `extract_failed` | 无法提取内容（如 OCR 失败） | 检查截图清晰度，重新上传 |
| `oversize` | 文件超过 50MB | 压缩文件或分批上传 |
| `unsupported` | 不支持的文件格式 | 转换为 PNG/JPG/CSV/XLSX/PDF |
| `pipeline_error` | 数据还原管道错误 | 查看日志，检查数据格式 |
| `move_error` | 文件移动失败 | 检查磁盘空间 |

**查看日志**：
```
ve4/logs/receiver.log    # 接收器日志
ve4/logs/pipeline.log    # 数据还原日志
```

## 五、常见问题

### Q1：手机搜索不到电脑蓝牙？

- 确认电脑蓝牙已开启且"允许被发现"
- 确认电脑和手机距离在 10 米内
- 尝试关闭并重新打开双方蓝牙
- 重启电脑蓝牙服务：Win+R → 输入 `services.msc` → 找到"Bluetooth Support Service" → 重启

### Q2：配对时验证码不显示？

- 部分设备配对时无需验证码，直接配对即可
- 如果提示输入 PIN 码，尝试输入 `0000` 或 `1234`

### Q3：传输速度慢？

- 蓝牙传输速度约为 1-3 MB/s，大文件请耐心等待
- 建议在 WiFi 环境下使用 VE4 App 上传大文件

### Q4：文件传到电脑后在哪里？

- 文件最终落入 `ve4/incoming/` 目录
- 处理完成后移动到 `ve4/incoming/processed/YYYYMMMDD/`
- 原始备份保留在 `ve4/incoming/` 的子目录中

### Q5：可以一次传多个文件吗？

- 可以。多文件会排队处理，每个文件独立触发数据还原管道

## 六、安全提示

1. **仅配对可信设备**：不要与陌生设备配对
2. **传输完成后关闭蓝牙**：不使用时关闭蓝牙，减少攻击面
3. **文件本地处理**：所有文件仅在本地处理，不会上传云端
4. **加密存储**：处理后的数据存入 SQLCipher 加密数据库
