VEfinsteward 是100%由AI codingd编辑的应用，所用的模型为deepseek v4 flash 和pro
VE的初衷是做一款让用户能够自己真正掌握自身财务隐私的本地AI财务管家应用。当前用户的财务隐私分布并隔离在不同金融机构的数据孤岛中，这些数据被实质性垄断并用于各种商业营销工作。也就是说，用户不仅不能真正地掌握自己的财务隐私数据，还无法拥有单独统一的、具备专业能力的、没有营销意图的个人财务管理应用。试想一下：
1. 你是否希望分散在不同账户的资金能否被统一的进行资产配置管理？
2. 你是否希望能够有应用，帮你在任何时间预留好任何计划下的流动性资金？（当然，我们拒绝信贷广告的轰炸）
3. 你是否希望这个应用，能够帮你规划好你的生活安排，包括食谱、出游、日用品清单？
4. 你是否希望这个应用能够帮你管理好投资计划，包括大类资产配置与具体的投资战术？能同时具备基本面分析（价值投资）、技术分析、量化分析（需要接入数据）？
5. 你是否希望你的习惯能够被智能的 RAG 分类管理，且增删权利（个人的偏好设置）永远都在自己而不会被第三方拿去定点营销？

这就是VE想给您带来的价值。记账很重要但 “记账” 一点都不重要，投资理财很重要但 “投资理财” 一点都不重要，真正重要的是让用户能够真正掌握自己的财务隐私、在掌控了财务隐私之后去做的其它一切事情 —— 这与互联网时代的逻辑不同，互联网时代做分割的事情，垄断用户的隐私、在平台护城河中生存；但 AI 应用时期却是让用户真正掌握自己的隐私（出售能支持本地 AI 长期挂机运行的设备）、AI 计划一切而不是让用户陷入营销广告轰炸、让用户的喜好和 AI 的创意推荐来塑造人的喜好而不是用算法制造信息茧房。
我们基于 FastAPI 后端 + pywebview 桌面窗口 + PWA 前端构建。在目前，用户可以利用手机截图（证券持仓、银行余额、消费账单等），自动提取财务数据，由VE在此基础上完成资产配置分析、消费结构诊断、生活规划建议和目标追踪，并利用配置的AI API据此生成experience和life-plan。所有数据存储在用户本地。我们也推荐用户使用的LLM也是本地模型。
